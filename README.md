# מנטור החומרה — Hardware Learning Mentor

אפליקציית לימוד אישית בעברית (RTL, mobile-first) ללימוד חומרת מחשבים צעד אחר צעד,
שנבנתה במיוחד למי שמתחיל תפקיד בולידציית חומרה.

## הרצה

```bash
npm install
npm run dev
```

ואז לפתוח בדפדפן: http://localhost:3000 (במובייל או במצב מובייל ב-DevTools).

## מה יש בפנים

- **בית** — ברוכים הבאים, התקדמות כללית וכפתור "המשך ללמוד".
- **שיעורים** — מודולים זמינים: המעבד (CPU), CPU ו-PCH. מודולים עתידיים מסומנים "בקרוב".
- **שיעור** — כרטיסי לימוד קטנים, אחד בכל פעם: הסבר, דימוי מהחיים, מונחים, תרשים, סיכום ושאלות חזרה.
- **מבחנים** — שאלות אמריקאיות עם משוב מיידי והסבר; נשמרת התוצאה הטובה ביותר.
- **מילון** — מונחי חומרה בעברית פשוטה עם דוגמאות, כולל חיפוש וסימון "למדתי".
- **התקדמות** — שיעורים שהושלמו, תוצאות מבחנים, מונחים שנלמדו והמלצה לצעד הבא.

ההתקדמות נשמרת ב-localStorage בדפדפן — אין צורך בשרת או בהרשמה.

## מבנה הקוד

- `lib/content.ts` — כל תוכן השיעורים והמבחנים. להוספת מודול חדש: מוסיפים אובייקט `Module` ומסמנים `available: true`.
- `lib/glossary.ts` — מונחי המילון.
- `lib/storage.ts` + `lib/useProgress.ts` — שמירת התקדמות ב-localStorage.
- `components/` — רכיבים לשימוש חוזר: `LessonCard`, `TermCard`, `QuizQuestion`, `ProgressCard`, `ModuleCard`, `SimpleDiagram`, `BottomNav`.
- `app/` — המסכים (Next.js App Router).

## טכנולוגיות

Next.js 15 · TypeScript · Tailwind CSS 4 · localStorage בלבד (ללא backend).
